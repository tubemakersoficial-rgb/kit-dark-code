# Prompt de instalação (aula 1.2)

Cole este prompt numa sessão do Claude Code e envie. O kit fica em https://github.com/tubemakersoficial-rgb/kit-dark-code

```
Instale o Kit Dark Code neste computador:

1. Baixe o kit de https://github.com/tubemakersoficial-rgb/kit-dark-code para uma pasta temporária, com o Git.
2. Antes de instalar, leia o instalar.py e me diga em poucas linhas o que ele faz.
3. Rode "python instalar.py --ver" e me mostre a lista do que será instalado.
4. Se estiver tudo certo, rode "python instalar.py".
5. Me mostre a lista de skills e agentes instalados e me diga como eu uso a primeira.

Não instale nenhum programa além do kit e não rode nada além do instalar.py.
```

Depois de instalar, abra uma sessão nova e digite `/` para ver as skills.
