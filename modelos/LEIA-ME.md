# LEIA-ME — como esta pasta funciona

Cada vídeo do canal passa pelas pastas abaixo, na ordem. É como uma linha de montagem:
o vídeo começa como uma ideia em `pesquisa` e termina em `publicados`.

| Pasta | O que vai dentro |
|---|---|
| `pesquisa/` | Ideias de vídeos, anotações, links, fatos e fontes sobre cada tema. |
| `roteiros/` | O texto que vai ser narrado, já pronto para gravar. Um arquivo por vídeo. |
| `audios/` | A narração, a legenda `.srt`, músicas e efeitos sonoros. |
| `imagens/` | As imagens e cenas que aparecem no vídeo. |
| `videos/` | Os clipes e o vídeo montado. |
| `thumbnails/` | As capas que aparecem no YouTube antes da pessoa clicar. |
| `publicados/` | O que já foi ao ar: vídeo final, título, descrição, tags e a data. |
| `ferramentas/` | Scripts que ajudam na produção. Não é uma etapa do vídeo. |

## Dica para não se perder

Dê a todos os arquivos de um mesmo vídeo o mesmo nome, com um número na frente:
`roteiros/001-nome.md`, `audios/001-nome.mp3`, `thumbnails/001-nome.png`.
